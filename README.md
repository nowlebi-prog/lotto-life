# 로또 라이프

혼자 즐기는 한국어 픽셀·블록 웹게임입니다. 가입과 진행 저장 없이 다음과 선택지를 눌러 한 편의 이야기를 끝냅니다.

- **무조건 1등 체험:** 표 받기 → 게임 속 QR·번호 확인 → 축하 연락 → 준비물 → 은행 방문 → 수령 → 20개 첫 행동 중 선택 → 전용 엔딩.
- **시뮬레이션:** 1등 표 확률 **1.5%**. 꽝·소액 당첨·번호 착각·다수 당첨·분실·회차 착각·세탁기 등 10개 시나리오와 선택 분기.
- 남자 10종·여자 10종 중 성별에 맞는 고정 외형 무작위 배정. 닉네임과 외형은 한 판 동안 유지합니다.
- 결과 카드 PNG 내려받기, 효과음 선택, 모션 줄이기, 키보드 조작과 모바일 표시를 지원합니다.

## 실행

Node.js 22 이상이 필요합니다. 외부 라이브러리 설치는 필요 없습니다.

```sh
npm run build
npm start
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다. 개발 중에는 `npm run dev`로 원본을 바로 확인합니다. 포트가 사용 중이면 `PORT` 환경변수를 다른 값으로 설정하세요.

ES 모듈을 쓰므로 `index.html`을 더블클릭하는 대신 위 서버 또는 정적 호스팅으로 여세요. 이 서버는 로컬 미리보기용이고, 배포에는 서버 프로그램이 필요 없습니다.

## 검증

```sh
npm test
npm run check
```

선택 가능한 모든 큰 사건, 성공·실패 분기, 잘못된 동작, 중복 수령 방지, 등수·보너스 판정, 외형과 번호의 고정, 남녀 모두의 20개 엔딩 연결을 확인합니다.

### 시뮬레이션 확률

| 결과 | 한 판의 확률 |
| --- | ---: |
| 1등 표 | 1.5% |
| 2등 | 0.5% |
| 3등 | 1% |
| 4등 | 8% |
| 5등 | 20% |
| 미당첨과 회차 착각 | 69% |

이는 실제 복권 확률이 아닌 게임 설정입니다. 1등 1.5%에는 기본 1등 1%, 다수 당첨 0.3%, 분실 0.1%, 세탁기 0.1%를 모두 포함합니다. 이미 1등인 표를 분실하거나 훼손하는 선택으로 수령하지 못할 수 있습니다. 각 판은 독립 추첨이며 연속 실패에 따른 숨겨진 확률 보정은 없습니다. **1등 보장 체험 모드는 계속 100% 성공합니다.**

10,000개 등간격 난수 구간을 빠짐없이 검사해 총 150구간이 1등 표임을 검증합니다. 이는 실제 플레이 10,000회에서 반드시 150번 나온다는 뜻은 아닙니다.

브라우저 검증은 개발 도구 Playwright가 설치된 환경에서 `npm run test:browser`로 실행합니다. 이 도구는 앱 실행에 필요하지 않습니다. 미리보기 서버를 먼저 실행하고 기본 Chromium을 설치해 주세요. 다른 포트는 `TEST_URL`, 설치된 Edge는 `BROWSER_CHANNEL=msedge`, 도구 위치 지정은 `PLAYWRIGHT_MODULE` 환경변수를 사용합니다.

## 정적 배포

`npm run build`가 만든 **dist 폴더의 내용 전체**를 정적 호스팅에 올리면 됩니다. 빌드 결과는 상대 주소를 사용하므로 `/저장소이름/` 경로에서도 동작합니다. API 키·환경변수·DB·런타임 서버가 없습니다. 이미지 전체는 약 1.3MB입니다.

### GitHub Pages

1. 이 프로젝트를 새 GitHub 저장소에 올립니다. `node_modules`, `.qa`, 비밀 정보는 포함하지 않습니다.
2. 저장소의 **Settings → Pages → Source → GitHub Actions**를 선택합니다.
3. `main`, `master` 또는 `codex/lotto-life`에 푸시하거나 **Actions → Verify and deploy Lotto Life → Run workflow**를 실행합니다.
4. 테스트와 빌드 뒤 `github-pages` 배포 주소가 나옵니다.

처음 올릴 때 쓸 명령 예시는 아래와 같습니다. URL은 본인 저장소로 바꾸세요.

```sh
git init -b main
git add .
git commit -m "Launch Lotto Life"
git remote add origin https://github.com/YOUR-NAME/lotto-life.git
git push -u origin main
```

이 소스에 포함된 `.openai/hosting.json`은 별도로 만든 비공개 Sites 미리보기의 식별 정보이며 비밀 키가 아닙니다. GitHub Pages 배포에는 사용되지 않습니다. 독립 프로젝트로 Sites를 새로 만들 경우 기존 미리보기의 ID를 재사용하지 마세요.

## 데이터와 비용

- 진행 상태는 열린 탭의 메모리에만 존재합니다. 새로고침하면 처음으로 돌아갑니다.
- 로그인·분석·진행 저장·IP 추적·다른 이용자 피드가 없습니다.
- 게임에서 닉네임을 업로드하지 않습니다. 카드 이미지는 내려받기 버튼을 누를 때만 생성합니다.
- 호스팅 업체의 일반 접속 로그나 브라우저 정적 파일 캐시는 게임 진행 저장과 별개입니다.
- 실행 비용은 정적 파일 전달 중심입니다. 구체적인 요금과 무료 한도는 선택한 호스팅의 현재 정책에 따릅니다.

## 이야기와 실제 로또

번호, 회차, 당첨 여부와 금액은 게임 시나리오입니다. 20억·5억·7,000만·150만 원은 연출용 수령액이며 실제 회차 상금이나 세후 금액 계산이 아닙니다. 복권 구매·번호 예측·실제 연락·송금 기능은 없습니다.

종이 복권의 QR 확인, 번호 재대조, 실물 표 준비, 1등의 본점 방문 경로를 [동행복권 공식 가이드](https://www.dhlottery.co.kr/guide/wnrGuide)와 [로또 소개](https://www.dhlottery.co.kr/lt645/intro)를 참고해 구성했습니다. 화면·직원 대사와 세부 장면은 창작 연출입니다. 공식 안내 확인일은 2026년 11월 1일입니다.

그림은 이 게임을 위해 imagegen으로 생성했습니다. 외부 게임의 캐릭터·텍스처·브랜드 로고를 가져오지 않았습니다. 아트 그리드와 제작 기록은 `docs/art-assets.md`, 구현 기준은 `docs/spec/product.md`, 검증 기록은 `docs/verification.md`에 있습니다.
