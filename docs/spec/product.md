# 로또 라이프 구현 기준

- 한국어 픽셀·블록 웹게임. 두 모드: 무조건 1등 체험 / 랜덤 사건 게임.
- 브라우저 메모리만 사용. 로그인, DB, 진행 저장, 분석, IP 추적, 외부 사용자 피드 없음.
- 성별(남자 또는 여자)과 닉네임만 입력. 성별별 10개 고정 프리셋 중 무작위 배정. 같은 판 동안 외형 고정.
- 1안은 종이 가상표 받기, 게임 속 앱·QR 확인, 재대조, 가족/친구 반응, 준비물, 다음 은행 영업일 전환, 본점 방문, 가상 수령, 20개 중 첫 행동 선택, 전용 장면과 카드.
- 1안은 모든 선택에서 1등 수령 성공. 표 분실·등수 하락·상금 삭감 반전 없음.
- 2안은 한 판에 큰 사건 1개와 작은 대화 선택 최대 2개. 기본 1등 / 많은 당첨자 / 2등 착각 / 3등 정정 / 분실 / 회차 착각 / 세탁기. 숫자와 회차는 판 도중 불변.
- 2등은 일반번호 5개와 보너스 일치. 3등은 일반번호 5개와 보너스 불일치.
- 20개 첫 행동은 1안과 2안의 1등 수령 성공 판에서만 제공. 2등·3등·미수령 판은 해당 결과 카드.
- 선택한 엔딩은 랜덤으로 바뀌지 않음. 성별에 관계없이 20개 전부 가능.
- 수령은 게임 속 허구이며 실제 번호 예측·복권 구입·금융상품 추천·실제 외부 연락 없음. 실제 개인정보 입력 없음.
- 모바일과 PC 대응. 키보드 조작, 명확한 포커스, 모션 줄이기, 음소거. 효과음은 기본 꺼짐.
- 장면과 대사는 건너뛸 수 있음. 능동 진행 기준 5~10분 목표. 대기 때문에 자동 실패하지 않음.
- 끝에서 사용자가 직접 엔딩 이미지를 내려받을 수 있음. 자동 저장과 수집함 없음.
- 새로고침은 초기화. 처음으로 이동 시 현재 판만 버림. 빠른 연속 클릭으로 장면·수령이 중복되지 않음.
- 정적 빌드와 소스, README, 테스트, GitHub Pages 자동 배포 설정을 최종 패키지에 포함.
